# Floodgate 2025の取得・実手数付き評価基盤 (2026-09-20)

対象: H-FLOODGATE-2025、H-DECISION-REPLICATION。

## 結果

ユーザー指定の2025年公式CSAアーカイブを取得し、配布元公開SHA256との一致を確認した。
対局時の双方のratingが3500以上という条件を厳守して、実手数・元棋譜ID・履歴付きデータを作成した。
H-FLOODGATE-2025は測定完了。棋力仮説H-DECISION-REPLICATIONは未判定のままである。

| 項目 | 件数 |
|---|---:|
| 原棋譜 | 128,843 |
| 採用棋譜 | 38,351 |
| 採用棋譜の全着手前局面 | 5,710,803 |
| rating不足 | 72,560 |
| rating/対局者名の欠損・重複 | 16,025 |
| 未完了・異常終局 | 340 |
| 異常summary（時間切れ・反則等を含む） | 1,391 |
| 同一全着手列の重複棋譜 | 176 |

採用棋譜は1月から12月をすべて含み、対局者名は374種。
手数帯は1–40手目1,533,563局面、41–100手目2,212,449局面、101手目以降1,964,791局面。

棋譜hashによる固定分割後、1棋譜1局面の集合はdevelopment 11,454、validation 7,678、
test 7,739、match 11,332。これらの間で棋譜・抽出局面が重ならず、既知の旧24,995局面との
重複もない。match poolから別途8棋譜を費用測定用、10,000棋譜を正式追試用として固定した。
旧accuracy・日次growth-v1を変更していない。エンジン対局・再学習は実施していない。

## 証跡と検証

- [取得・派生データmanifest](manifest.json): 元URL、公式hash、設定、全出力hash、分布、除外元。
- [固定対局用集合manifest](match-plan.json): cost8、本番10,000、予備1,324のhash。
- [全件検証ログ](verification.txt): 全38,351棋譜と5,710,803局面を再生し、手数・SFEN・着手・
  評価値視点を照合。固定集合の棋譜分離・局面重複・履歴・旧集合除外も検査。
- [別パーサーによる照合](independent-parser.txt): 200原棋譜で既存cshogi CSAパーサーと
  対局者・rating・全着手・評価コメントを照合し一致。
- [利用・再生成手順](../../../operations/floodgate2025.md)。単体検査はrating境界/欠損/非数、
  対局者対応、手数・履歴、異常棋譜、年、重複、archive安全性/CRC、再現性を確認した。

最終版の全件生成108.00秒。大量小ファイルへの展開は途中で打ち切り、
公式archiveを直接streamして全memberのsize/CRCを検査する実装に切り替えた。
正常な入玉宣言の二重記録、summaryのみの最大手数引分・連続王手終局も保持した。
この対応前の試行版は-initialへ退避し、本結果には混ぜていない。

## 研究計画への反映

今回の原棋譜取得により、従来HCPEで欠けていた実手数・元棋譜ID・全着手履歴を保持できる。
新しい対局用10,000棋譜も確保できた。ユーザーに同等データの追加提供を求める必要はない。

従来計画の「pretraining祖先を含む完全分離証明がなければ停止」は今後の開始条件にしない。
確認できた重複除外とその範囲を記録し、未確認の祖先分離は結論の限界として扱う。
既存優先順位は維持する。次のH-DECISION-REPLICATION準備で本データを利用し、
対局条件・元棋譜履歴の扱いを固定、cost8で費用測定後、6時間以内のchunkへ分ける。
元の保留attemptの記録は消さず、そのreviewと新しい実施計画は区別する。

評価値は各対局者の報告で、共通探索器の教師ではない。bestmoveは原棋譜の着手である。
raw/full corpusは序盤や転置の重複を保持するため、全局面を独立標本として扱わない。
2025年コーパスを導入しただけで新しい棋力仮説を支持したとはしない。
