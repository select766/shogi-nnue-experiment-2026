# 24時間 学習量・検証深さ拡張計画 (2026-08-27)

実行枠は2026-08-27 22:50から2026-08-28 22:50 JSTまでとする。一次対象は
`H-ROOT-SEARCH-STATS-STRENGTH`と`H-SU-JOINT-DIRECTIONS`である。

一次結果後の残時間は次の優先順位で使う。

1. 一次対象が正方向で不確定なら、事前に定めた未使用局面で局数またはroot数を拡大する。
2. 一次対象が明確な負方向なら、過去の`H-DECISION-ALIGNED-LOSS`を深掘りする。この仮説は
   validation/test bestmoveが`+0.13/+0.11`pt、4,000局が`+7.30 Elo`と全て正方向で、既存仮説中
   最も棋力へ近い未確定信号を持つ。既存4,000局と重ならない開始局面を追加し、最大12,000局へ拡大する。
3. 残り6時間未満で長い対局を完了できない場合は、joint方向のfresh root追試またはroot統計の
   固定bestmove追加splitを優先し、途中結果を完了扱いにしない。

root統計の対局延長はvalidationの同一shuffle（seed 20260826）で未使用の4,200--6,199番を使い、
追加2,000開始局面・4,000局、一次と合計8,000局とする。decision-aligned延長へ分岐する場合は、
既存validation開始局面とは別の`accuracy_eval_10k/test.jsonl`からseed 20260827で4,000開始局面を固定し、
追加8,000局、既存分と合計12,000局とする。

各分岐は一次結果と残時間だけで決め、同じheld-out/test結果を用いた目的重み・方向・checkpointの
再選択は行わない。終了時に実行時間、完了条件、未完了ジョブの有無を結果文書へ記録する。
